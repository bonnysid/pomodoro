Pomodoro 0.2.3

• Обновления через GitHub: проверка, скачивание и установка из настроек.
• Установка начинается по нажатию, после паузы таймера и сохранения данных.
• Новый цикл в новый день и ручной возврат к первой сессии без удаления статистики.
• Русский и английский, пресеты 25/5/15 и 50/10/30, свои длительности.

Версии 0.2.2 и старше нужно обновить вручную один раз: механизм автообновлений появляется в 0.2.3.
macOS: эта сборка пока без подписи Apple, автообновления на ней отключены. Подписанные сборки будут доступны после настройки сертификата.

English: GitHub update checks, downloads and manual installation are now available in settings. Timer data and statistics are preserved. Install 0.2.3 manually once to enable future Windows updates. The unsigned macOS build requires manual updates.
