Pomodoro 0.3.1

• Добавлено подключение оригинальной спокойной музыки из установленного Minecraft Java: Sweden, Minecraft, Clark, Wet Hands и другие треки. Открой «Фоновые звуки» → «Подключить музыку Minecraft». Для нестандартной установки выбери папку assets.
• Плейлист повторяется по кругу. Работают прослушивание, общая громкость, пауза и режим «Играть и без таймера».
• Файлы музыки читаются с твоего компьютера и не включены в установщик. Minecraft должен предварительно загрузить свои ресурсы.
• Иконка настроек заменена на шестерёнку.

macOS: сборка по-прежнему с технической подписью, без Developer ID и нотарификации. Предупреждение «Apple не удалось подтвердить…» может остаться. Для доверенной сборки доступно «Конфиденциальность и безопасность → Всё равно открыть». Полное устранение этого предупреждения требует подписи Developer ID и проверки Apple.

English: Connect original calm music from your installed Minecraft Java assets. The local playlist repeats and supports preview, volume and playback outside focus. No game audio is bundled. Settings now use a gear icon. macOS still uses ad-hoc signing; Developer ID notarization is required to remove the unverified-software warning.
