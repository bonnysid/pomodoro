Pomodoro 0.2.4

• По завершении фокуса, короткого или длинного перерыва окно появляется поверх остальных — в том числе из трея и свёрнутого состояния.
• В настройках поведения добавлен переключатель «Показывать окно по завершении». По умолчанию включён, выбор сохраняется после перезапуска.
• Временный показ окна не меняет постоянную настройку «Поверх других окон» и сохраняет мини-режим.
• Статистика, пресеты и остальные настройки сохраняются при обновлении.

Windows: обновление доступно из настроек версии 0.2.3. Для 0.2.2 и старше нужна ручная установка.
macOS: текущая сборка без подписи Apple, обновление вручную.

English: The timer window now comes to the front when focus or either break finishes, including from the tray or a minimized window. Disable “Show window when timer ends” in settings if preferred. The choice is saved; mini mode and the separate always-on-top preference are preserved.
